# Agent 区域改版说明

2026-10-09。范围限唯一可点击原型；不修改生产代码、不操作正式应用、不读取或传递真实凭据。所有安装、连接、认证、模型读取与请求结果均为演示。本说明不代表已修复安装版问题或逐家真实接入通过。

## 信息与导航

Agent 目录显示当前正式 29 项。`agent-directory.js` 对应 `docs/agent-first-release.md` 的精确 `directoryId` 与正式 `directoryName`，图标和简介原样取自现有 `public/agents` 与品牌展示数据。既有演示 `id/name` 保留，避免破坏已保存草稿及只有名称的对话。当前 10 个代表条目沿用已有能力样例，新增 19 个条目只显示目录身份、能力未提供，不编造登录或模型能力。

“我的 Agent”卡片提供明确的“管理设置”，仍可新建对话；管理直接打开“程序／账号与服务／模型”共用分区。未完成首次使用的 Agent 仍保留准备进度，首次使用仍经过原有完成校验，管理入口本身不把它标为可用。首次接入的三个阶段可直接跳转，程序未就绪或工作进行中时保留限制。

账号身份、服务来源、模型与请求验证分栏展示。只展示明确给出的身份字段；供应商名称和登录方式名称不是个人身份。“未提供身份信息”不解释为未登录。能力说明改为可扫描表格，区分目录、能力样例与真实请求未验证，详细依据折叠。

## 可操作流程

- 打开设置时，对已添加、闲置且待检查的程序自动启动演示检查；失败保留显式重试，取消不会无限自动重试。正常页不再显示“连接／断开”主操作。
- 更新和更换程序前显示当前与候选范围。空闲连接自动结束；候选失败、取消或结束结果未知时，已有程序选择及服务配置保留。忙碌或结果未知时阻止变更，并提供待处理对话入口。
- 移除 Agent 只有一套确认。默认只撤回接入和已选服务授权，保留程序、账号配置与历史；可明确勾选卸载 Farfold 管理、没有其他引用的程序。外部安装不能勾选，未提供的退出账号能力不伪造按钮。
- 程序版本、安装来源和接入组件版本分别展示，路径与多份程序列表默认折叠。
- 登录方式按声明的类型显示“账号授权／终端登录／API 密钥”，官方名称保留在次要信息。多个登录方法点击即启动所选流程，无额外确认登录页；原方法消失时可明确选择替代项，不自动换账号。
- 已保存 API 服务与当前选择分开；保存提示明确“尚未选用”。当前模型区常驻来源；变更后展示进入时与本次选择的来源、模型、推理等级，确认后才使用。
- 模型读取失败保留原选择；未提供选项明确说明可沿用 Agent 配置，不把“未提供”说成没有模型或账号不可用。
- 自定义接入的关闭、取消与 Esc 共用未保存退出提示，可继续填写、放弃或保留后恢复。来源／模型／推理变更退出时同样可保留草稿或放弃；运行中操作支持暂离并保留进度。
- 注册入口未提供时，只在已知目录说明链接存在的情况下给出清楚标注的说明页，不编造专用注册链接。

## 独立复核后的补充（2026-10-09）

恢复“程序路径与高级管理”中的独立旧版本卸载，不必先移除整个 Agent。只有未选用的受管理版本显示操作；忙碌、结果未知、版本仍在使用或被其他 Agent 引用时禁用。范围确认列出目标版本和路径，明确保留当前程序、接入、账号、服务与历史；提交时再次校验状态。旧版本清理不结束当前连接。

目录状态统一为“可以使用／未完成设置”；程序检查中的等待、失败与未知状态分别显示，正常卡片不再把“已连接”作为用户目标。演示标识和请求未验证依据继续保留。

管理上下文复核结论：`draftForEntry` 不会按全局入口自动忽略 `initialSelection`。调用方须为全局管理清掉对话的 selection、active 和 folder；全局导航隔离由主任务负责。

补充验证：程序状态、独立卸载、统一接入和 29 项首次进入的 174 项测试全部通过。新增状态及渲染用例核对旧版本清理的范围、忙时保护、外部程序保护、跨 Agent 引用保护和当前配置保持。
