2026-10-09。仅修改唯一可点击原型，不改正式应用，也不读写真实配置、密钥、历史或文件。产品依据为当前 `PRODUCT.md`，旧 README 与契约冲突时以契约为准。审查编号取自 `docs/evidence/2026-10-08-ui-coverage-audit/full-review/all-pages/data.json`。

## 已实现的交互

- **通用设置**：外观、对话整理、更新与诊断、数据与隐私形成明确分组；页内索引可直达。已有归档规则、保存失败及任务保护保持。
- **数据与隐私**：数据归属先给结论；清除范围与卸载说明是两个独立入口。清除逐项列出 Farfold 目录/设置、未发内容、受管理程序、安全存储密钥与应用对话文件夹；逐项说明 Agent 账号/配置/历史及用户项目仍保留。有未结束工作或保存失败时禁止继续。勾选确认后仅展示清除结果示例，不删除当前演示数据。
- **诊断**：范围说明 → 可选问题文字 → 按四类预览内容 → 确认导出结果示例。填写内容明确原样加入，预览可返回修改；没有创建或上传文件。
- **更新**：未检查、检查中、无通道、失败、当前版本、新版本分别呈现；无通道可查看原发布渠道手动更新步骤，避免只有无法行动的状态。原型不捏造发布链接或下载更新。
- **API**：保存到目录、在 Agent 中选用、确认模型后开始分为三步。来源变化显示原地址/格式与本次值对照；旧密钥失效保护、模型校验、测试取消与保存失败继续有效。新增配置放弃时不再声称存在“上次保存”。帮助不再要求先填写服务方，提供具体准备步骤和服务控制台内容示例，可显式补齐空字段；不打开无法核实的官网链接。
- **对话库**：搜索边界直接说明；活动、未发内容、待回应、进行中、新回复、归档分别筛选并显示数量。行内显示位置、草稿/待发和归档状态。收藏空态说明星标操作。删除与清空当前归档范围先预览具体对象，待处理工作、未知结果、队列和未发内容受保护，不部分删除。
- **移动与全局搜索**：移动显示具体对话及当前分组，选目的地后再确认；未改变分组时不能重复提交。全局搜索包含工作位置与归档，结果显示位置与时间；无结果可清除。
- **带入已有对话**：Agent 名称搜索、无匹配恢复、分页加载、失败重试和暂离保留选择；正文和继续能力单独列出，原模型与来源始终可见。只读或正文未取得时可单独重新检查，检查仍未知不升级为可继续。已加入项不重复加入，部分失败仍按原逻辑保留失败选择。
- **LifeModel**：保留未启用说明与批准边界，不增加假采集、假保存开关。
