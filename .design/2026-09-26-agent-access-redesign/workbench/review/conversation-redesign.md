## 对话设置与发送

- 入口：输入框下方 Agent＋模型。服务、账号身份和地址集中在同一摘要；未知身份明确写“账号信息未提供”。
- 完成／已确认停止后，只展示父级根据当前 Agent 和来源提供的模型与推理；没有列表时保留原值，不能猜测能力。
- 点击“确认并保存”后先进入等待。匹配本次操作的成功回执才更新下一条消息基准；失败保留旧值；结果未知锁住发送，提供“核对本次设置结果（演示）”。
- Agent、服务和工作位置始终保留；已存在消息不会改写。配置更新暂停已有队列，用户明确继续后才发送。
- 审批、回答、正在运行、停止未知、恢复未完成、权限未确认期间，配置表单展示不可改原因。
- 归档菜单禁用时同时显示具体原因，避免只灰掉按钮。

## 独立导出

- 入口：右上“对话操作”→“导出 Markdown”。打开时快照当前已展示的用户／Agent 示例消息，正文前写明交互原型，不读取隐藏历史，也不附带输入草稿与待发消息。
- 准备中显示“取消准备”；取消会清除本地计时，不影响对话、菜单或输入。
- 准备成功显示实际文件名与消息条数，点击“下载 Markdown”才由浏览器下载本地生成的 `.md` 文件；“文件已准备好”不等于声称已保存到磁盘。
- 失败显示原因，可“重试准备”或关闭。没有已展示正文时明确失败，不用任务标题或预设历史补造 Agent 正文。
- “原型场景”内有成功、首次失败后重试成功、持续准备可取消三个演示选项。持续准备特意用于核对取消出口，不能被理解为正式导出成功。
- 导出或重命名弹窗关闭后，下一帧把焦点还给持久存在的“对话操作”按钮；切换对话或隐藏对话时不抢焦点。针对浏览器发现的 Escape 关闭后焦点落到 WebArea 问题做了局部修正；相关状态与渲染测试 37/37 通过，实际焦点由主任务复查。

## 状态与下一步

对话底部“原型场景”集中放置演示入口，不把情境切换器混入消息记录。可以选择：完成可继续、审批待处理、问题提交将未知、停止未确认、历史恢复权限重确认；也能选择模型配置成功／明确失败／未知的返回结果。

- 审批只处理当前操作，保留具体对象和权限范围。
- 回答提交未知保留选择与说明，禁用重复提交；“检查回答提交结果（演示）”展示确认后继续。
- 停止等待、发送停止失败和停止结果未知分开；未知先“检查停止结果（演示）”，不把没有回执写成停止成功。
- 历史恢复需要回执、完整正文与原模型／推理核对齐备；随后仍须重新确认权限。恢复、确认和继续待发是三个独立动作。

## 文件与网页内容栏

- 文件模式保留第一版／第二版标签。文件意见按路径＋内容版本保留；看新版时旧意见仍展示原版本与行位置，不冒充最新行号。
- 失败页可返回文件列表；其他文件可直接查看。底部折叠“文件预览场景 · 演示”可触发单文件失败、恢复、第二版。
- 右上“网页”打开静态内容示例。初始不授权；工具请求确认写明 Agent、具体 URL、仅当前页和只读范围。
- 收起后通过“网页”或输入标签重开，许可保留。换 URL、关闭页面或演示连接结束撤回。恢复／明确连接关闭也撤回。
- 撤回文案说明已经交给 Agent 的内容不会因此删除。这里没有执行真实读取；本地 HTML 成果预览也不等于网页工具授权。
