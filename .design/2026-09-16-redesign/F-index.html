四条设计原则 · 一切界面的推导起点
01
主界面 = 调度台
侧栏只剩新对话、搜索、会话列表。Provider、LifeModel、归档、更新等低频配置全部收进左下角唯一设置入口。
02
产物 = 通用窗格
diff、网页、表格等产物共享同一承载层，由对话流中的内容链接唤起。顶栏无常驻窗格按钮，浏览器无专属地位。
03
身份 = 可扩展系统
14px 圆角 logo 块 + 身份色 + 名，为 N 个 Agent 设计。未知 Agent 用中性灰首字母兜底，接入新 Agent 不改任何结构。
04
状态 = 三级词汇
需要你（琥珀）/ 在跑（靛）/ 静默（无标）。「需要你」自动排前，注意力即排序，不再设独立待办区。
