- Agent 接入：三内置定义、本机发现、安装、自定义命令及 initialize；任意 registry 浏览、`/Applications` 扫描尚未实现。
- 对话与任务：统一正文、工具步骤、队列、停止、模型选择；本轮真实 Codex 5.5 回复和隔离文件任务成功。当前 CLI 拒绝 6 Astra，要求升级；本轮未修改或升级 Agent。

- 历史：元数据索引与 Agent 提供的历史；无 Farfold 对话数据库。新日志不存正文，旧原始日志仍留在本机。
- LifeModel：静态页、关闭的开关与空注入接口；无真实采集、治理或注入闭环。
- 发布：0.1.7、macOS arm64、ad-hoc 签名，无默认公开更新源；不宣称稳定日用或公开发布就绪。
