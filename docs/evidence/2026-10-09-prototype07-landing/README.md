## 尚未完成与安装边界

源码和受控呈现不能判定全产品 UI/UX 已验收。系统文件选择/导出、真实通知送达与声音、真实停止与恢复、登录/API 和 29 家 Agent 八项标准仍需各自证据；本轮未发送真实消息或作真实 Agent 验收，未清除用户数据；启动应用可能触发当前所选连接的正常准备。Windows、官方更新渠道和正式签名分发保持原边界。
