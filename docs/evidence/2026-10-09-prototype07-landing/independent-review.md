## 草稿、配置与数据保护

- `saved-new:` 保存未发文字、附件及所选 Agent/来源/工作位置/配置；保存原草稿成功且文字、选择、发送状态和清除序号仍一致后才能替换。存储失败保留原内容，恢复后的图片重新核验；恢复保存失败保留两份副本及全局保存错误门禁。
- `resend:` 与主输入草稿独立，已经纳入持久化、未发筛选、配置输入忙碌及 Rust 归档保护。重启回归证明内容保留；未知发送复用原队列，不自动再次发送。
- 模型/附加设置只有正式 setter 及保存回执成功后成为发送基线。UI 待确认值、已确认值与结果未知保持区分。历史服务的缺失、变化、删除、不可用模型及读取失败不再自动沿用当前来源。
- 归档删除已冻结用户看到的筛选范围，并在执行前重新核对；范围后来增加、目标取消归档与忙碌保护由 settings/library 同事的专项回归覆盖。本复核未改其实现，不重复宣称实际删除已测。
- 自定义接入未保存内容仅按用户操作保存在当前进程内，不落盘可能含秘密的环境变量；程序更换与账号/API 动作继续走既有真实设施。

## 产品契约与范围

此次保留一套通用 UI 与官方执行入口，没有复制原型回答、假回执或计时器作为真实能力；没有新增第二个 Agent 循环、品牌专属 UI、私有 HOME、Agent 配置写入或模型正文账本。新增草稿内容继续进入已有 Farfold 未发送内容存储，服务 revision 是非秘密核验信息，Keychain 秘密不写入请求元数据、日志或报告。

新增四个文案模块已纳入 `strings.test.ts`：`REDESIGN`、`AGENT_REDESIGN`、`CONVERSATION_REDESIGN`、`SETTINGS_REDESIGN`。集中术语测试通过；新 Rust 用户提示另行核对，无禁用工程术语。AST 字符串扫描命中的 class 名、命令名、字段名与诊断文件键属于内部标识，不当作用户文案。
