## Copilot 运行中停止

一次停止前，独立进程检查确认命令 shell 为 Copilot 原生进程的直接子进程，sleep 为该 shell 的直接子进程。正式通信记录 19:07:17.239 发出一次停止，8 毫秒后收到回复。再次检查时两进程已消失，早于自然 45 秒期限，检查方没有向它们发信号。本次证明这一对进程确实在停止后提前结束；旧版曾出现的后台进程未随停止退出仍是独立负例。附带监测器把带空格的父进程路径拆错，虽见 60 个精确 shell 参数样本，不能用于确定两个进程的结束时间；结论以独立的停止前后进程检查为准。

Copilot 原生记录同一轮 `user_abort`，有该工具开始但无匹配的工具完成事件。正式应用显示「回复已停止，仍有步骤未确认结束」，标题却仍写「进行中」。原输入框当时为空，禁用的发送按钮不能证明另写新消息也会被拦截。没有强行重连、重启或重跑该命令。此次实测没有验证未完成工具回执的恢复或其他命令/子孙进程组合。[停止回执契约](https://agentclientprotocol.com/protocol/v1/prompt-turn#cancellation)
