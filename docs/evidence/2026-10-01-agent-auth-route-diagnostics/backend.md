| 现有失败点                               | 固定说明                                                           |
| ---------------------------------------- | ------------------------------------------------------------------ |
| 无效标记、标准/旧登录字段格式错误        | 此登录方式提供的信息不完整或格式不正确，请在更多登录方式中明确配置 |
| 程序路径或绝对脚本路径无法确认           | 无法确认此登录方式的程序路径，请检查程序或在更多登录方式中明确配置 |
| 解释器启动不属于可核实的简单绝对脚本形状 | 此登录方式的启动参数尚不能自动确认，请在更多登录方式中明确配置     |
| 已解析目标与当前选中程序/入口不同        | 此登录方式的程序与当前程序不一致，请在更多登录方式中明确配置       |
| 同解释器但两个绝对脚本入口不同           | 此登录方式的脚本与当前程序不一致，请在更多登录方式中明确配置       |
| 其余已有无法核实的声明                   | 沿用原固定“未能确认对应程序”说明                                   |
