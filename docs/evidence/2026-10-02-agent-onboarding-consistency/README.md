## 改动与依据

- 程序 → 账号与服务 → 模型；新连接先进入账号，用户按实际条件继续。已有步骤、模型、思考及来源保留，不自动发送。见[前端红绿与边界](../2026-10-02-agent-setup-order/frontend.md)及[入口审查](../2026-10-02-agent-setup-order/scope-review.md)。
- 账号区统一“登录与账号设置”标题及可访问名称，所有终端方法仍复用同一 `InlineTerminal`。使用与管理入口的提示按上下文区分，方法、进行中状态和真实失败按事实呈现。
- Auggie 提供了完整终端声明，旧捕获器错误拒绝嵌套环境。修复通用声明保真和执行合并，保留精确程序身份、当前连接归属及公开信息脱敏。见[后端原因、官方依据与红绿](../2026-10-02-agent-terminal-auth-env/backend.md)。
- 首批目录审核 41 个身份，保留 33 个候选、暂缓 8 个；未审核的新条目不自动加入。只筛选探索展示，已有程序、配置、管理和历史保留。完整理由及验证边界见[首批名单](../../agent-first-release.md)。
