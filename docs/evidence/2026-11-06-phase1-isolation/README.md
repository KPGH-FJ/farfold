# 第 1 阶段：同 Agent 多对话隔离

正式应用仍是 `6ce829c5`。两组实测各用两条自有对话，组内同一 Agent、同一自有空目录、同一服务和已选模型，原会话 ID 与正式通信连接不同。A 等自己的工具审批；B 只生成文字。观察到 A 等审批且 B 已运行后，只在 A 点击一次停止。两组原稿均未作发送输入：先走保留草稿流程，结束后恢复同一份原稿。保存值摘要一致，原保留数 1 和原工作位置保持；自测目录仍空。

| Agent   | A 实际结果                                                                                                           | B 实际结果                                                            |
| ------- | -------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Goose   | 唯一审批等待归 A；只向 A 发一次停止并回复其审批，界面显示已停止。                                                    | A 停止后继续输出，20.318 秒返回专属标识并完成。B 通道无停止、无审批。 |
| Copilot | 唯一审批等待归 A；只向 A 发一次停止并回复其审批。界面显示已停止，原生记录交互拒绝及同轮 `user_abort`，缺该工具终态。 | A 停止后独立完成，4.473 秒返回专属标识；原生该轮无工具或停止。        |

两组 A 均保留「回复已停止，仍有步骤未确认结束」；没有批准本次 A 请求，没有把缺回执的步骤改为完成。该证据覆盖同 Agent 同目录的停止、审批归属和另一对话不受影响；不扩为已运行工具的结束、模型切换隔离、永久许可或完整八项。

Goose A 的原生模式为 `approve`，B 在这次纯文字并发中为 `auto`。B 前一条独立测试实际执行了一次无文件和网络操作的固定文字输出，未产生审批。原因是选择 `approve` 后还需点击「确认更改」，本次只完成选择，未提交；独立日志没有该模式的出站设置，原生当前值仍是 `auto`。这条结果不计作手动审批测试或产品忽略已保存设置。两条 Goose 均沿用 OpenRouter / Nemotron 3 Ultra (free) / off；Copilot 两条均为已有设置 / Auto / Agent / Allow All Off。

## Copilot 工具回执对照

正式版旧运行中停止样本的原生记录仍保持封存的 51 行，找不到同一工具完成；内容无关的正式通信记录在停止与回复之间只有一条通用更新，未保留其类型和工具 ID。这不足以单凭旧文件确定官方是否发出同一工具终态。

使用已登记的官方程序直连，运行时明确返回 Copilot CLI 1.0.106。第一次准备因测试脚本对选项的判断错误提前结束，零模型请求。严格核对 Auto、Agent、Allow All Off 后，在另一个自有空目录做一次有界命令对照。两项精确单次审批通过；没有在运行时取得足够的进程归属证据，因此没有发送停止。命令自然结束，官方原始通信直接返回同一工具的 `tool_call_update: completed`，与原生同一工具完成事件吻合，原请求随后返回 `end_turn`。这验证正常结束的回执路径，与停止样本分别计证。 [Copilot 官方直连接口](https://docs.github.com/en/copilot/reference/copilot-cli-reference/acp-server) · [1.0.106 发行说明](https://github.com/github/copilot-cli/releases/tag/v1.0.106)

## 保留条件

本机复验长等待取证探针：九项只读文件元数据检查通过；用自有 FIFO 触发短时等待，采到 48 次系统文件打开栈，释放后子进程正常退出。实测中没有复现先前的桌面路径长等待。自然复发时用同一时间窗并行记录实际进程、文件访问步骤与两跳管道归属；不自动重发或人为扩大访问范围。

Kilo 跨版本授权和安装版写入故障继续单列：当前正式应用仍未替换，且尚无隔离的 macOS 图形测试账号或实例。
