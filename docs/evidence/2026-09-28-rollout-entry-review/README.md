# 落地方案前的入口核对

2026-09-28。本次仅为制定后续推进方案而核对当前界面，没有修改生产代码、安装程序、登录、发送消息或清理数据。不是完整产品验收，也没有重新验证各 Agent 的认证能力。

## 操作范围

1. 查看用户当前打开的原型，处于“终端登录与注册”评审场景的 Agent 列表。
2. 打开该示例的“查看进度”，观察等待授权、返回、取消及暂离入口；未点击模拟授权。关闭面板后回到原列表。
3. 查看正式应用当前对话；它已包含用户清空重装后新建的工作，不能再当作空白安装。
4. 进入“探索 Agent”，观察保留的“自定义”筛选及零结果状态；没有改变筛选或点击重新发现。
5. 点击“返回对话”，确认回到原先对话，未输入或发送内容。
