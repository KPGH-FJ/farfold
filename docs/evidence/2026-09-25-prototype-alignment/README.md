## 仍需明确的产品边界

- Agent 独立准备测试不会用连接检查或 API 直接调用来冒充；本轮先传递真实服务/模型到新对话，在对话里验证。
- 无可靠未读元数据，不伪造「新回复」状态；没有工作完成证据时也不将空闲标记为「已完成」。
- 真实目录没有可靠用途分类，不凭名称猜用途标签。
- 通知、声音、LifeModel 是原型提案，不能照搬模拟开关与模拟成功。
- 内容意见在加入当前对话草稿前，切换文件会丢失；Markdown 尚无段落定位。已加入草稿后的内容遵循现有草稿保存路径。
- 完整 J1–J6、干净登录、更多 Agent、既有模型恢复与性能未达项仍按原记录开放。
