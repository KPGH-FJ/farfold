## MiniMax MiMo 发送暂停复现

原安装版在独立草稿选择其已有设置中的 `mimo-v2.6-flash`，重开选择器确认选项生效，输入保留且「发送」禁用。协议 `protocol-v1-1794851425251-3.jsonl` 有 `session/new`、两次成功响应的设置更新及零 `session/prompt`、零审批。展开原始卡片看到 `config_option_update`。严格配置确认原来只在消息区条目为零时解除自身暂停，保留下来的配置通知也被算入，因而阻塞首条消息。

源码现在仅把已归类的原始配置通知视为准备信息。明确确认仍要求同一对话、连接、有效配置回执和现有活动保护，原始事件保留。定向回归先复现「配置已确认、首条仍被锁住」，再证明允许一次手动发送。混入其他未知事件、已建立或恢复的对话及已有队列仍保持原保护。共用模型选择器同时修正无替代项时的只读显示，托管服务只在实际返回的模型标识与已选服务精确匹配时使用可读名称。
