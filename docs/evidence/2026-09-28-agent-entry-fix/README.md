# Agent 首次接入入口修复

日期：2026-09-28。范围：当前交互原型 `.design/2026-09-26-agent-access-redesign/workbench/`。

## 已修复

- 未完成首次接入时，目录主按钮和设置图标都进入三步向导。只有连接成功、尚未确认使用方式的旧记录仍需继续准备。
- 新对话入口和首次发送采用相同判断，不能绕过确认步骤。
- 首次完成记录与当前配置状态分别保存。连接、登录或服务变更不再抹掉首次完成记录；日常管理仍用于已完成接入的 Agent。
- 暂离与重启恢复原步骤；历史、导入和既有对话保留自身上下文，不替另一份草稿完成接入。
- 内置示例的完成标记不会流入首次状态或缺少完成记录的旧状态。没有完成证据的旧状态需再次确认准备。
