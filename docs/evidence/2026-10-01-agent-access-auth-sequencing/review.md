| 边界         | 最终源码与反例核对                                                                                                                                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 启动前取消   | 同一 Attempt 可取消本地目录验证、配置锁等待与连接准备；配置锁取得后再次检查。已发出的协议认证保留原请求 owner，不借本地等待取消提前释放未知请求。                                                                                                        |
| 环境读取前后 | 共用终端启动段在读取前后检查同一状态。读取同时失败并取消时，先检查取消，再传播读取错误，返回 `AUTH_CANCELLED`；新增失败环境反例覆盖此顺序。同步环境或 Keychain 读取一旦开始不能中途撤回，本片不承诺零读取。                                              |
| 终端真实退出 | 同一 `abandoned` 标记传给既有 `spawn_controlled`，原 PTY owner 继续回收子进程及所属进程组。退出 sink 持有配置锁、账号操作锁与 Attempt，收到真实退出帧后释放；启动交错不被描述为绝对未创建子进程。                                                        |
| 回执与锁释放 | `Mutation::finish` 先释放已完成 mutation，再唤醒调用者。真实关闭成功先移除 route，再完成回执；调用者超时或停止等待时，原 mutation 和锁仍保留至实际结果或连接结束。受控 oneshot wake 与真实迟到关闭回归分别覆盖该次序。                                   |
| 已关闭重试   | 默认关闭行为保留，只有明确 `allowAlreadyClosed` 使用缺失重试策略。查询及锁错误仍传播；同 Agent、同目录的全部非候选来源中，connecting/closing 或仍含该标识的 owner 不能被当作已结束。其他目录或候选不替代该目标判断，已有 route 的 token 与状态检查保留。 |
