不修改第三方 Agent 或适配器源码，不重写执行循环、模型调用、压缩、停止和历史。官方操作仍会按用户意图改变会话状态、工作位置或可用工具；“不改 runtime”不等于这些操作完全不影响行为。

能力 允许的实现层 不能越过的边界
预览、用量展示、通知、输入、工作树 Farfold 展示或管理自己拥有的工作环境 不宣称工作目录是安全沙箱；不迁移正在运行的原会话
Steer、压缩、分支、历史恢复、删除 核实并调用 Agent 官方接口 不以停止后重发伪装steer、不新建空会话伪装恢复、不自行拼接原历史
技能/MCP发现和配置 官方声明、接口或用户明确交接 不偷偷改私有配置；通用市场是另一个范围决定
网页工具 向会话提供有授权和撤回语义的host工具 增加工具会影响可用能力；不能声称所有Agent已覆盖
