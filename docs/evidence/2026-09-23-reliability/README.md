## 性能口径与原始失败

同机、实际窗口 1199×768，复用既有数值诊断；输入事件至两次 requestAnimationFrame 是下一绘制机会的观测上界，不是 CPU 渲染时间。仅接纳 `visible=1 focused=1 visibility_changed=0` 样本，每轮 100 次输入、30 次切换；输入 p95 ≤100ms，切换 p95 ≤200ms。记录主进程 RSS/线程；无法归属的 WebKit/GPU 数据不计作全应用内存或帧率。

[旧安装基线](baseline-performance-summary.json)：千条历史三轮输入/切换 p95 分别 32/227、32/202、33/192ms，前两轮切换失败。128KiB 已载入文本的三个有效轮次为 47/140、31/109、31/130ms。双路实时仅一轮完整有效；另一轮期间已结束，其他自动化失焦/调用失败的轮次保留为无效，不能补记通过。

首候选 30 次预热历史切换 p95 151ms 仅为 [探索样本](candidate1-performance-exploratory.json)，不作为最终性能验收。
