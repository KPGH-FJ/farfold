2026-11-06，唯一正式应用 `/Applications/Farfold.app`，功能版本 `6ce829c5`。使用桌面外自有空目录中的 Copilot 自测对话，图片是独立生成的静态 PNG，4096×4096、6,917,984 字节。本次只有正式实测和受影响检查，未改功能或重装。
