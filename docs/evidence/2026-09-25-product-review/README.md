# Farfold 全产品评审 · 2026-09-25

**结论：存在会影响实际工作的缺陷。当前产品处于内部 Alpha：真实工作链路和新版界面已经整合，接下来应收口连续使用的可靠性与端到端验收。尚不能称为稳定日用或公开 Beta。**

这个判断来自产品契约、当前生产源码、唯一安装版的实际操作、三个并行源码审查和针对测试。不是按页面数量或测试数量估算完成百分比。本文是评审结果，没有实施产品修复。

## 工程验证与下一阶段

本轮并行执行的前端针对测试合计 15 文件、127 项通过（75 对话/恢复、25 接入、27 工作台）。Rust ACP 59 项通过、2 项真实 Agent 测试忽略；凭据、服务、API、认证、安装的过滤测试均通过，其中范围有重叠，不相加伪造总数。现有认证测试使用独立非账号 Keychain fixture，不使用真实服务凭据。详情见分报告。

当前候选此前全量前端 186、Rust 186（3 项忽略）及格式、类型、打包、clippy 已通过；本轮核对源码一致，没有把旧全量检查写成本轮重新执行。新发现正说明“测试通过”和“用户旅程无缺陷”不是同一结论。

下一阶段建议按可验收结果推进：

1. **保护连续工作**：草稿及文件意见可恢复；所有归档入口不隐藏活动/待批准任务；普通历史完整交付后再允许续发。
2. **统一接入与状态**：区分正常闲置和未知结果；修正认证连接选择、终端取消及准备重试；统一筛选与首发后的推理选择规则。
3. **关闭真正的产品出口**：在同一安装候选复验 J1–J6，保留选定模型/推理，覆盖干净登录、真实新服务使用、并行审批、停止和重启。对外部恢复限制保留明确失败，不能用换模型、第二条执行路径或原型成功状态代替。

完成这些后才有依据评估进入封闭 Beta。当前最应投入的是既有能力的可靠性，不是继续增加页面数量。
