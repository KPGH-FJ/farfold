# 选定FLAC文件API时长诊断

2026-10-18，仅核对两个既有受控静音样本，未运行正式应用、Agent或浏览器。完整证据与SHA见[核验记录](verification.json)。

55字节原件与187字节PADDING对照，通过同一次修正后的Apple文件API consumer，均读满至EOF：8000Hz、单声道PCM16LE，800帧、1600字节、0.1秒，输出逐字节相同且全零。没有创建声音输出设备，不作可听播放结论。

R1先错误要求压缩输入的bits为16；实际为0，测试在PCM设置和读取前自行失败（读取0次、退出1），不是系统解码失败。原回执保持。R2核验真实客户端PCM格式，单次consumer自然退出0，每个样本读取2次并确认EOF；输入、PCM哈希与关闭状态已核对。

两文件的有效样本800、名义包长4096、余量3296及文件API时长0.1秒一致。旧WebKit的0.512秒与名义包长数值相合，但未确定具体责任层，也没有浏览器PCM证据。原55字节error4及PADDING对照的旧观测保持；没有加入填充或时钟变通措施，不称播放修复、正式媒体成功或P13完成。
