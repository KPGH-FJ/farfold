# 安装前启动模型审阅：前端证据

本记录覆盖声明驱动的界面、安装请求传递、公开输入保存和受控状态回归。起点为 `a1bb4c5`。前端子任务没有启动 Agent、运行配置程序、安装正式应用或读写用户凭据；安装验证由主任务另行记录。

## 已实现

- `AgentPrerequisites` 将同一次准备查询结果传给程序页；`AgentInstallOptions` 根据通用声明展示字段、官方说明和本次启动参数。首次安装与程序管理中的更新使用同一份审阅输入及安装入口，没有品牌分支或额外批准流程。
- 模型参数是可选覆盖。首次不预设模型，留空并点击安装表示沿用目录与已有程序的启动设置；重装时呈现后端从原参数确认的 `currentValues`。用户明确清空后，界面说明此次不追加模型参数。连接检查失败仍是失败，不把已有配置推定为可用。
- 接入层确认的公开目录默认值通过字段 `catalogDefaultValue` 只读显示，不填入输入框、`currentValues` 或提交的 `values`。界面说明实际使用由 Agent 的已有设置和启动参数决定，不声称目录默认必然生效；不读取或展示原程序的环境内容。fast-agent 的目录环境键在原快照中已存在，不将本次补充说明写成目录新加了默认值。
- 安装输入属于 `AgentSetupProgress`，与会话的 `selection.config`、API 服务和全局草稿分开。原稿及原有准备范围继续沿既有 Hub 进度保存；取消、失败和暂离不会自动重试或改变原会话模型。输入不自动修改已注册程序；普通连接、重新连接及历史程序选用继续沿已有启动目标。
- 安装请求携带声明身份、目录版本、原启动形状和公开值，不接收前端任意执行文件、额外参数或环境变量。后端重新核验当前声明；前端遇到声明身份、版本或原参数变化时保留旧输入供查看，要求重新填写或明确沿用启动设置。同版本和原参数下仅声明身份变化也受此保护。
- 支持有界公开模型名称及官方模型代号，保留字面值，不修剪或截断。不支持的编辑仅留当前输入框并禁用安装，不能被转换为空值后安装，也不写准备存储。旧安装字段解析失败只保留安全的重新填写标记，原会话选择和其他旧进度仍可读取；被拒绝的原文不再写回。
- 准备查询未取得结果时不当作声明删除。刷新或读取失败期间保留旧输入、阻止安装，不显示可以误清输入的“沿用”动作；只有成功查询并确认声明缺失时才显示声明变化。
- 模型重读要求改为中性操作提示，不再与真实失败并列声称“尚未检查”，也不引用与实际按钮不一致的名称。

## 证据边界

这些回归使用真实前端控制器、组件回调及存储逻辑，安装返回为受控对象。它们不证明 fast-agent 已通过连接、认证、模型读取或真实回复，也不关闭先前安装失败。输入规则刻意只覆盖当前核实的公开名称和模型代号；网址、查询参数等高级规格没有实现，不应静默改写后尝试。
