## 进程观察

- Kilo 原历史的34个内核管道快照覆盖22.510秒，均有486字节留在子进程输入，输出和错误输出均无积压。另一次程序检查的子进程在读取当前工作目录时停在系统打开调用，同一栈观察到48次；该程序检查的实际目录未核实为应用默认目录。
- Goose 原历史的18个快照覆盖11.593秒，三个标准管道均无积压。另对同次读取的进程采样，48次落在历史恢复准备的 `current_dir → getcwd → __open_nocancel` 分支。该次正式应用最后收到12条更新。
- 先用自有进程的7字节输入和13字节输出核对了计数。现场快照保留计数，进程采样仅公开已选符号结论。两家都观察到同类目录解析停滞；具体打开目标、调用结果、权限决定以及共同根因仍未知。
