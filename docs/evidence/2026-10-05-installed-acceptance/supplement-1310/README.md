## 共用模型控件修复

官方Cline接口把Provider和Model都放在model类别，旧实现选择首项，因而把提供方错误显示为模型。现在多项同类别时优先唯一的model标识，再选唯一的Model名称；歧义保留在原选项列表，不猜第一项。单项任意标识和旧版无类别兼容保持，没有Agent专属UI分支。提供方仍留在原会话选项中，原保护继续生效。

本轮仅改 `src/runtime/session_projection.ts` 的选择函数和新增9项回归。合并工作区176文件2008项通过、受影响133项及最终回归9项通过；精确选择源码4文件71项及类型检查通过。两份额外组件回调测试在隔离副本62项通过，未写入仓库，避免纳入依赖的既有未提交开发。[检查摘要](checks.json)。
