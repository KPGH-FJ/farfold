## HTML 存档与清除

- 项目身份来自当前任务的 `thread.cwd`，与文件核实回执的 root 分开。后端规范化项目目录及准确文件路径，稳定散列为专用 UUID 与 HTTPS 来源。同项目同文件不同入口/别名复用，不同项目或文件分区；更新内容不丢分区，移动/重命名不迁移旧分区。
- 文件仍经原完整回执读取，只把内存 HTML 给独立 WK；没有扩大文件/目录读取权限。领先 CSP、禁止联网/嵌套内容与无应用桥保持。
- 清除 UI 仅对实际持久本地页回执出现，先就地确认当前项目/文件。操作检查当前 scope、task、active、visible、busy，旧确认不能作用于新页。
- 后端只接受当前 task+label，从已有准确页面取分区，串行关闭后调用该 UUID 的官方数据清理。没有接受外部存储路径或枚举/清空所有分区。
- 原清理超时后，Objective-C 层同分区在途保护仍持续到官方回调，防止迟到清理擦除新打开页写入。失败不冒充清除成功，不自动重开。
- 较旧 macOS 仍临时，回执明确表示；当前公开网页仍临时且不能触发 HTML 清除。
