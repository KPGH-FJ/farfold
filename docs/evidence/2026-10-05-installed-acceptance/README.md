## 本轮修复

- **先开网页再发送**：新对话在已有工作文件夹和准备完成的Agent下，使用已预开草稿打开现有内容栏。原输入框、文字和附件保持；首发继续原发送与未知结果保护，开页本身不发模型消息。
- **返回待回应不取消网页请求**：访问列表或切换任务先隐藏页面，再继续导航；返回时保留原页和仍有效的请求。明确关闭、打开替代页面、取消、超时及连接结束仍按真实回执处理。隐藏失败时明确选择“关闭网页并继续”会取消原请求。
- **HTML按项目和文件保留存档**：macOS14+使用专用WebKit分区，同项目同文件不同入口／路径别名共用；不同项目或文件隔离。更新文件内容保留该分区，移动项目／重命名文件不自动迁移。较旧系统仍临时且界面明确说明。
- **只清当前文件存档**：先确认，再关闭并清除当前项目中该文件分区的数据；保留原HTML和其他项目／文件／外部浏览器资料。超时或失败不假报成功，迟到清理结束前禁止该分区重开／重复清理。
- **文件打开行为一致**：交付文件“打开”与消息路径复用已核实文件查看，HTML在网页栏、文字在内容栏，继续重读和意见加入原输入；不自动发送。

持久存档保存的是页面自行写入的进度与偏好，**不会保存运行中的JavaScript内存，也不恢复Agent读取许可**。仍只支持资源内嵌的单文件HTML；禁止联网和嵌套内容，无应用接口，不给网页目录读取权限。公开网页继续使用临时环境，本地HTML不自动分享给Agent。
