# Copilot 禁用登录：后续最小验证范围

2026-10-01。只读本批公开证据、当前认证/安装源码，以及本批登记目录中三个官方包文件。未读取数据库、凭据、用户配置、进程环境或协议正文；未启动应用、Agent、登录或测试，未改生产源码。本文件不更新本批安装结论。

**现有非秘密诊断不足以确定这一次目标核验失败的具体原因。**可以证明当前保护为何可能拒绝 npm 启动器与平台程序的不同入口，但不能据此认定现场声明就是这一形状。登录仍是未测；禁用不证明账号未登录。

## 已确定的边界

- [公开登记](copilot-registration.json)与[账号页文字](copilot-auth.txt)记录：包及自报版本 `1.0.89`，选中绝对 Node + 同一受管目录的 `npm-loader.js` + `--acp`；方法为 `copilot-login`，现场提示“此登录声明未能确认对应程序”，普通登录按钮禁用。[原诊断](copilot-auth-diagnosis.md)已保留截图与官方文档边界。
- [协议元数据](protocol-metadata-final.json)只有时间、方向、事件、字节数和固定错误类别，没有认证目标或路由拒绝原因。[采集器](collect_protocol.py)明确只投影这六类字段，不能用回复大小或 stderr 字节数补出原因。
- [公开登记采集器](observe_registration.py)只保留方法 ID、名称、类型和变量名。它没有保留公开声明中已有的 `_farfoldInvalid` 布尔标记，因此 `containsExecutionFields:false` 既不能证明声明有效，也不能证明声明里本来没有执行字段。没有在本次调查中重新查询数据库来补这个信息。
- [Handshake](../../../src-tauri/src/acp_client/handshake.rs) 的 `public_method`（第 164 行）移除命令、参数、环境值和旧扩展，公开快照可保留无执行内容的无效标记；真实执行声明只在所属连接内存里。[认证方法查询](../../../src-tauri/src/auth.rs) `methods_for_target`（第 413 行）仅同目录、已有来源的实际连接可授权执行，缓存/API 来源返回另外的固定不可执行说明。
- [目标路由](../../../src-tauri/src/acp_client/auth_route.rs) 第 223 行起将无效声明、旧扩展字段错误、参数/环境形状错误，以及无法核实目标等分支合并为 `Route::Unavailable`；[UI 方法派生](../../../src-tauri/src/auth.rs) 第 72 行起再合并为同一固定提示。当前没有可从既有安全诊断恢复的细分原因码。

## 下一片建议

1. **先使原因可验证，再补可执行路线。**沿现有单一 `Handshake`/目标验证增加有限原因枚举，例如声明无效、目标不可解析、解释器入口形状不支持、入口不一致；只保留固定码和公开方法 ID，不存错误正文、命令参数、环境值或完整声明。必要的身份信息投影为布尔关系：是否同选中程序、同脚本、同受管包平台入口。现有 `_farfoldInvalid` 可在下一次被授权的公开观察中保留，不能由名称/description 推定有效。
2. 真实连接中对 `copilot-login` 取得该安全判定后，若确认是同包平台入口的旧终端路线，再沿现有配方/受管收据机制补窄关系：当前注册来源/目录/版本、实际已选收据、npm 清单 `bin`、平台依赖与导出、两个实际入口规范化后均在同根内，以及该方法的明确登录参数。输出冻结的已注册 Node + 同一绝对 loader + 官方登录参数。未知形状继续保持禁用和显式手动配置；不解析 description、不二次 PATH 替换，不把 `login` 接到 `--acp` 后。
3. 普通 `agent`/标准 Terminal 的声明语义保持；标准 Terminal 不受旧扩展补充改写。缺少实际声明或来源证明时先交付安全原因说明，不能为了使按钮可点而改走 `authenticate`。真实登录、浏览器授权、凭据保存仍需用户明确操作；没有账号条件可以验证目标、暂离/取消，登录成功继续记未测。

必要受控反例：同包 loader→平台入口可核实；其他安装、同名 PATH 程序、外部 symlink/目录逃逸拒绝；包/平台版本或入口不匹配拒绝；无效标记与畸形字段得到固定原因且不泄露 canary；同方法 ID 的未知参数不补充；标准 Terminal 原样执行；拒绝发生在 Keychain/环境交付及进程启动前，且不发 `authenticate`。这些是下一片待做范围，本次没有运行回归或真实登录。
