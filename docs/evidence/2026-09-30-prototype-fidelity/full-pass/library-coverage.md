## 当前安装版视觉与交互验收清单

以下均须使用同一最终候选记录实际窗口大小、主题和截图。至少宽窗及产品最小窗口 900×620；原型约 877×779 与安装最小宽度不同时明确记载，不将被系统约束后的尺寸写成请求尺寸。

### 静态视觉（无需账号或模型请求）

- 左栏品牌和收起按钮、导航顺序、选中层次、数量／草稿标记、Agent 图标、分组缩进、底部动态与设置；收起后展开入口不消失。
- 全部／收藏／Agent／分组页面的顶栏、标题／数量、继续草稿、搜索／下拉／整理、活动筛选标签、五个状态页签、列表行高和信息次序；长标题、长分组和无结果时不挤出按钮。
- 搜索弹窗的标题、X、搜索框、图标／标题／副行和归档标记、范围说明；短列表、长列表、无匹配分别检查，关闭控件始终可见。
- 行操作菜单位置；“整理 N 段对话”分组列表；重命名／新建分组字段和保存区；保存错误的可见位置。深浅主题、键盘焦点环与文字放大均需现场核对。
- 导入弹窗三步、Agent 卡片选中、来源／位置、查找状态、列表与预览、底部选择数和操作区；窄窗可滚动且主要操作不被裁剪。

### 当前可实际操作（只使用本轮新建样本，保护原数据）

- ⌘N／⌘K及鼠标入口；搜索按标题／Agent／分组／位置找到当前和归档记录；中文组词 Enter 不提前打开，普通 Enter 打开；Escape／外点／X 取消，回到实际打开按钮，背景审批快捷键不穿透。
- 库内 Agent＋分组＋状态＋搜索叠加，逐项清除，收藏页“清除筛选”仍是收藏；左栏交叉选择的维度规则；移除接入后的历史仍能筛选。全选仅选当前可见结果，切筛选不误操作旧选择。
- 新建／重命名分组、单条／批量移入／移出、取消、重命名对话、收藏；完成后原 Agent、来源、模型、位置和草稿不变。保存失败与迟到结果仅在真实可安全触发时验证，否则保留为工程测试覆盖。
- 空闲样本归档→归档内恢复；运行、审批、待发或未发内容时归档禁用并解释；恢复不因未发内容被禁止。归档不删除正文、不改变分组或对话身份。
- 库→对话→返回保持原筛选；设置／Agent 管理→返回原库或原对话；新稿→搜索／库→继续草稿保留正文与附件，不自动发送。
- 已有账号可用 Agent 的真实历史：查找、换 Agent／位置、搜索、预览、加入、去重、打开；导入→检查 Agent→返回保持查找与选择，关闭不自动加入或发送。真实不支持／列表失败／正文失败／只读与可继续必须分别呈现，不能以空列表冒充成功。
- 正常退出并以同候选冷开后，仅核对本轮样本的分组／收藏／归档／未发送内容与选择保留；同时核对原始索引和设置保护范围。

### 依赖真实外部条件的分支

- 某 Agent 的历史列表／正文／继续能力以及未登录→完成登录→返回导入，需要该 Agent 当前版本与真实账号条件。缺条件标未测或真实不支持，不归入“本地 UI 未对齐”。
- 大负载性能、新账号、新密钥／轮换及服务权益属于独立验收维度，不用于解释上述本地页面层次或交互未对齐。
