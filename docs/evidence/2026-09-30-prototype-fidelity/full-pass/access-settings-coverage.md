## 位置设置兼容语义

仍使用同一 `agentWorkPolicy.v1` settings 值。旧 `defaults` / `projects` 按 Agent 的设置继续按原含义读取，不自动扩大为整个位置。新增可选 `locations` 仅由用户明确暂停 / 恢复此位置时写入，并优先于旧 Agent 例外：`false` 对该位置全部 Agent 生效；明确恢复写 `true`，同时恢复该位置的发送资格，其他位置和旧记录不改。后端入场检查与前端状态共用此顺序。恢复仅恢复资格，待发内容仍需手动继续。

索引读取限 Farfold 自有元数据，不抓取全部 Agent 历史，不创建消息、事件或绑定账本。删除影响未知与读取失败分别显示，不据“尚未加载”宣称安全。
