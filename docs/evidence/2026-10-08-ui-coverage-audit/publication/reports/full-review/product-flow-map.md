## 产品职责与不属于本轮的扩张

| 对象       | Farfold 负责                                                 | Agent 或外部系统负责                                 | 观察时须分开的事实                                       |
| ---------- | ------------------------------------------------------------ | ---------------------------------------------------- | -------------------------------------------------------- |
| 接入       | 发现、安装/选程序、启动及官方接口交接、共用状态呈现          | Agent 的真实能力、运行与官方接入协议                 | 安装完成、握手完成、账号可用、模型回复分别记录           |
| 账号与服务 | 按声明显示方式；用户选择服务后交付；托管密钥留在系统安全存储 | 认证、账号权益、服务商计费；秘密由用户输入           | 认证方式存在不等于必须登录；终端退出不等于认证成功       |
| 对话       | 自有索引、组织信息、草稿/附件/待发、可见事件呈现和操作保护   | 推理循环、工具、权限决定、压缩、停止、真实历史与继续 | 索引出现、历史正文读到、可以继续、实际续答分别记录       |
| 模型与配置 | 展示实际声明；确认并保存选择；保护忙碌/未知结果              | 模型、思考及其他选项、配置回执、实际执行             | 列表、确认、保存、下一次实际生效分别记录                 |
| 文件成果   | 按用户明确入口核实磁盘、显示/打开/另存、意见回到原草稿       | Agent 写文件和修改文件；外部应用打开                 | 工具片段、磁盘文件、已看版本、修改后的新版本不是同一证据 |
| 网页       | 同窗内容栏、页面范围许可、请求确认/撤回、回执呈现            | 网页内容；Agent 发起真实工具请求                     | 页面打开、工具目录、许可、实际读取/动作成功分别记录      |
| 维护       | 自有数据、通知入口、诊断预览/导出、更新与退出保护            | 操作系统权限、文件选择器、安装机制、外部官网         | 按钮存在、请求发出、系统完成、重开后状态分别记录         |

Farfold 是独立多 Agent 桌面界面；不是编辑器，不重建 Agent 循环、不替 Agent 写用户配置或托管其历史。分组仅组织对话，工作文件夹才是执行位置，工作文件夹不构成 Agent 沙箱。LifeModel 当前仅有未启用页；不把真实采集、注入、移动端、多窗口或 Linux 加入本轮页面清单。Windows 源码适配不等于本机 macOS 走查已覆盖 Windows。

## 14 条用户任务链

每组列出主要入口、观察节点、条件与返回。关联旧 ID 见末表；共用界面不重复计算。此为任务框架，实际观察范围见[覆盖账本](coverage-ledger.md)。

### PF-01 准备新任务并保留草稿

- 入口与界面：新建→PF-V01→选 Agent/模型 PF-V12→配置 PF-V13、附加与附件 PF-V14；需准备时进入 PF-03/04/05，准备后回原草稿。
- 观察节点：有/无工作文件夹；可用/待准备 Agent 与无匹配列表；模型来源搜索；命令、模板、斜杠与路径建议；附件预览；切 Agent 的草稿处理确认；跨页回来与附件重新检查。
- 条件：无文件夹可以写草稿；发送或文件动作须明确位置，取消选择保留内容。只有文件夹和准备条件成立才可首发前打开网页；不自动把草稿记作已发送历史。命令选择可能写入草稿，附件选择会读取文件，不能归为单纯看菜单。
- 返回目标：原文字、附件、所选 Agent/来源及明确确认过的设置按其所属草稿保留；去设置和返回不等于另建任务。第一条消息被实际接纳后锁定 Agent、真实对话与服务来源。

### PF-02 发现或添加 Agent

- 入口与界面：探索/我的 Agent/设置的 Agent 与账号→PF-V04；详情 PF-V08；自定义 PF-V09；准备进入 PF-V10，开始使用进入 PF-V01。
- 观察节点：目录、分类、关键词、已准备筛选、空结果/载入/错误；声明能力和外链；自定义表单完整滚动、校验、取消。自定义程序选择是 PF-V24 的系统分支。
- 条件：29 项是当前首批目录身份范围；历史中的已移出 Agent 仍可能保留索引，不能按目录计数误删。声明能力与可运行能力分开，不按品牌另造流程。
- 返回目标：详情关闭回原目录；取消自定义不新增登记；准备结束回原入口意图，保留搜索/筛选。设置中的 Agent 与账号是路由入口，不额外算一个独立账号页。

### PF-03 准备、选择或移除程序

- 入口与界面：首次准备/已接入管理→PF-V10 程序步→PF-V11 安装、依赖、路径/版本管理及危险确认。
- 观察节点：未安装、已有程序、平台不支持；依赖指引；检查/安装进度、取消、失败/回收未知；当前程序与接入组件信息；展开其他安装；旧版本卸载和移除 Agent 的范围预览。
- 条件：首次准备与已有接入管理共用外壳，进入模型步可能自动准备连接；不能推定三步始终强制逐一执行。候选检查和回收确认后才选用；失败/取消/未知保留旧目标。实际工作/审批/未知结果阻止破坏性操作。
- 返回目标：首次连接后转账号与服务；已有管理返回原目录或任务。移除默认撤销 Farfold 授权与登记，历史仍在库；可选卸载只含归属明确、未使用的受管程序，官方退出账号是另一选项。预览取消不证明卸载或退出完成。

### PF-04 选择账号与服务并完成必要认证

- 入口与界面：PF-V10 账号与服务→PF-V11 已有设置/方式列表/终端/密钥/服务/官方准备配置；需要管理 API 时进入 PF-V06 再回原选择。
- 观察节点：已有身份摘要与认证需要检测；明确需登录、可继续、检测失败/重试；类型分组与官方名称；所选方式执行；终端显示/隐藏；注册外跳返回；管理接入展开、退出/换号确认、活跃工作定位；失败、取消、超时与未知。
- 条件：免登录、已有凭据、可选登录无需强行登录；`authMethods` 存在不能直接判必须登录。选定方式可能立即执行认证。认证方法专用 Key 和完整模型服务不同；手动命令只在官方声明允许时出现。账号动作可能影响同 Agent 的其他对话，不由独立进程推断账号隔离。
- 返回目标：认证确认后进入模型或返回原任务；暂离保留实际进行中的操作与终端所有者，取消需要真实结果。注册回前台只重查认证需要，不自动发消息；换账号在退出实际完成后仍需用户明确继续登录。已有对话修复携带原服务/模型上下文，不静默改源。

### PF-05 确认模型、思考、权限和其他配置

- 入口与界面：PF-V10 模型步、PF-V12 新建模型列表、PF-V13 已有对话配置；显式单模型测试表单在 PF-V11。
- 观察节点：实际模型/思考/附加选项；分组/搜索/来源；API 来源缺失或不兼容；读取准备中、空列表、不提供选择、需认证、失败；旧设置不一致、确认/保存/重新核对；权限范围及恢复后的重新确认。
- 条件：配置来自官方实际能力，现代/旧接口可以共用呈现但回执不同；模型列表为空不自动等同配置失败。首发前与已有对话的来源可选范围不同。已有对话可在请求确实结束后按实际能力改模型/思考；工具、审批、停止中或结果未知均阻止变更。只有确认且保存的设置成为后续与恢复基线。
- 返回目标：确认后回原草稿/对话；失败或未知保留选择与限制并提供核对，不声称生效。读取选项不是模型测试；测试表单打开、明确发起、取消回执、单模型响应分别记录。

### PF-06 找回、带入并打开既有工作

- 入口与界面：左栏/搜索/库→PF-V02；带入入口→PF-V18 的 Agent/位置→查询→列表/搜索/预览→加入→原库/目标对话。
- 观察节点：对话正文和历史载入；更多历史、不可继续/不支持/失败、权限恢复提醒；导入前置准备、查询中取消、结果完整/不完整/为空、重试、正文预览。
- 条件：打开冷历史可能启动 Agent 并读取其官方历史，不是纯本地静态浏览。列表来自官方查询，正文来自正式加载；搜索范围与分页完成度需分别呈现。目录中准备进度不能替代正文读取和继续能力。
- 返回目标：恢复沿原 Agent、位置、真实历史标识、服务来源和最近确认设置；失败留原任务/草稿/附件与暂停待发，不用空对话替代、不重放结果未知请求。导入返回原查询上下文；仅列出条目不等于已加入或可继续。

### PF-07 发起工作、回应请求并等待真实结束

- 入口与界面：PF-V02 输入区 PF-V14→PF-V15 工作内容/审批/问题；消息菜单 PF-V17 可编辑重发、再发一次或从这里新开。
- 观察节点：发送、待发列表/编辑、暂停/继续/放弃；发送未知、工具失败后的队列提示；思考/计划/工具展开、媒体与未知内容；工具审批的选项/作用范围/提交中/失败/回执；问题表单不同输入类型；停止中、停止未知、实际结束。
- 条件：这些动态状态需要真实任务或明确标注的受控证据，不能由按钮或旧消息推定。审批与问题卡属于原请求；停止点击不等于已停止，未知结果保留保护。重发/续发/队列继续是真实请求，不能为了看界面顺便执行。
- 返回目标：暂离后待回应定位回原对话和请求，观察不中断；完成/失败/取消依实际回执结算。恢复不自动发送待发内容，不复用旧审批。从消息新开进入 PF-01；其历史来源保护也受 PF-B05 约束。

### PF-08 查找、整理、导出或删除对话

- 入口与界面：PF-V16 全局搜索/对话内查找、PF-V03 所有/收藏/归档/分组/状态视图、PF-V17 行菜单/更多/整理/分组及危险确认。
- 观察节点：搜索结果和空结果、组合筛选；整理选择、全选当前结果、计数、退出；单条与批量归档/恢复/移组/删除、清空归档；分组新建/重命名/删除；导出保存选择器；相同设置再开。
- 条件：全局/库搜索为元数据，当前对话查找范围不同。批量作用于明确选中对象；活跃/未知结果可能禁止动作。删除 Farfold 索引与 Agent 侧历史删除的能力/回执不同；部分失败不等于全部删完。导出实际文件和保存结果单独验。
- 返回目标：取消回原库筛选/选择或对话；删分组的组织边界不等于删工作文件夹。相同设置新开进入 PF-01，地址/接口已变化或来源无效须重新明确选择，不能靠同 ID 或同名模型替代历史来源。

### PF-09 查看文件成果并提出修改意见

- 入口与界面：消息明确文件路径/附件/结构化位置或内容栏→PF-V19；系统选文件/打开/另存经 PF-V24；实际 HTML 转 PF-V20。
- 观察节点：文件与原始输出、轮次/筛选/栏宽；差异前后与并排/统一；核实中/成功/变化/缺失/权限/超限/失败；真实全文与重读；选行/全文意见、版本变化与未发意见；工具文本快照导出；静态 HTML 尺寸与实际打开入口。
- 条件：工具输入/diff 不是落盘证明；无定位可由用户选择明确文件，不扫描项目。点击绝对路径只选择该文件，不给父目录长期权限。核实、读正文、另存、外部应用打开各需相应结果；实际文件类型和系统限制会改变入口。
- 返回目标：文件意见带原任务与查看版本，只追加原输入区，发送由用户决定；换任务/重读失败不把旧正文或旧坐标冒充当前版本。完整返工还需 Agent 修改、重核和重开新版本，单次预览不完成返工。

### PF-10 打开网页或 HTML，并明确共享边界

- 返回目标：收起、切任务和普通浮层先隐藏实际网页，保留同页及未完请求；明确关闭、换页、替换或连接结束收回旧许可。受保护输入/登录期间暂停读取与控制，不绕到外部共享浏览器。清存档只作用当前项目当前文件，取消保留原文件及其他存档。

### PF-11 管理 API 服务而不隐式切换任务来源

### PF-12 调整日常偏好和发送管理

- 返回目标：关闭说明回原设置位置，外部系统返回不自动宣称授权成功；发送恢复以用户明确动作和实际结果为准。

### PF-13 诊断、更新、退出与清除自有数据
