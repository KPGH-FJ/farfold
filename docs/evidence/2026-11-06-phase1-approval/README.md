## Copilot 原会话和独立缺项

安装版草稿写入故障需要隔离的 macOS 图形测试账号或实例。若使用同一台 Mac，应先正常退出当前用户的 Farfold，再从隔离账号启动同一正式应用。只对测试库持有 SQLite 空写事务，验证保存失败、旧盘值和新输入保留、退出受阻、释放后重试和冷读；物理满盘及设备 I/O 另验。当前未注入生产库故障。Windows 安装仍待可用执行机。

## 退出期间尚未提交的审批

实际退出组件与受控原生事件复现三种交错：打开退出确认、选择留下、确认离开后保存仍在等回执。旧实现都把仍可撤销的「始终允许」发给 A。另两条受控用例覆盖打开中收到的审批移交到同一个对话后，退出锁保持或先释放；旧实现同样发出原选择。

源码沿用已有输入中断判断。尚未发出的选择被退出锁打断时保留原待审批项，解除这次选择，留下后只响应一次新的明确选择。已有回复回执、停止和取消保留原处理，B 的审批不变。此项验证的是 Farfold 的决定与发送时序，正式应用与官方持久规则另行留证。

新增五项由旧版五败转为全过，相关三文件 30 项、前端全量 724 文件 9,763 项、类型、格式、生产构建、文档检查及独立复核通过。后端输入与上一完整七项的提交相同。

## 退出中等待浏览器打开

在实际退出组件中扣住「同意并打开」的浏览器回执。进入退出确认、选择留下后解除锁、确认退出并等待草稿保存三种交错，旧源码均发出一次迟到同意，原询问变成等待结果。修复复用现有交互中断依据，保留同一询问，不从迟到的浏览器回执提交同意。

## 停止期间收到已提交的询问答复

在 A 的表单答复已经提交、回执尚未交付时触发停止。停止仍在等待，或取消传递失败而结果未知，两种旧逻辑都丢弃同一答复的明确回执，原询问一直显示正在提交。修复分开检查新答复能否发出和既有回执仍属于谁。只要原请求仍在，已提交答复的准确回执会结算；停止仍可阻止新同意。B 的待处理询问保持，A 无重复答复。受控两条反例由失败转为通过，相关 72 项通过。完整七项、文档检查与独立复核通过，前端 9,770 项，后端 2,421 项通过、7 项既有忽略。正式版和真实 Agent 复验待安全更新。

## 永久审批的隔离预检

Kilo 7.8.1 在独立新资料中读回指定模拟模型。第一条本机模拟请求暴露了两种工具，其中包括 Bash。夹具拒绝该请求，未返回工具提议，未选择权限或启动冷恢复。官方发行物中的迁移逻辑在非空旧配置未显式定义 Bash 时会补上允许；该次临时资料已移除，未回读实际迁移值。后续须在隔离资料明确拒绝 Bash，核到请求只列出读取，并在批准前独立核对准确路径及规则。原进程组正常退出，无真实凭据、远端请求或工具执行。[Kilo 预检](kilo-remember-rule-preflight.json)

另为 Kilo 两端口只做空套接字预检。两个指定 IPv4 端点通过，另一端口及同端口 UDP 被拒。占住已分配的备用地址仍有 12/208 种同端口竞争绑定成功，42 次备用 IPv6 试连有 4 次成功。地址集合前后相同，路由事件监听未完整结束。零 Agent 启动、远端连接或应用负载，未进入 Bash 拒绝或永久规则验证。[Kilo 端点回执](kilo-remember-rule-endpoint-ownership.json)

Goose 的预检只启动本机合成探针。精确 IPv4 地址规则被系统拒绝，可接受的 `localhost` 规则能挡另一端口，但同端口本机非回环地址和 IPv6 均可连接。保护范围未达预设条件，未启动 Goose，零模型、登录或生产写入。实际规则的保存、隔离范围和冷恢复继续待验。[Goose 预检](goose-remember-rule-network-preflight.json)

另一次只测端口准备。双栈套接字关闭复用并绑定到 `lo0` 后，在开始监听前仍有 264/372 种同端口竞争绑定成功。这个顺序无法证明端口独占。探针在监听前结束并关闭套接字，未测试竞争套接字能否接走实际流量，零 Goose 进程、凭据、模型和路由改动。[端口独占回执](goose-remember-rule-lo0-ownership.json)

新探针保持一个已监听的固定 `127.0.0.1` 端点，两种端口复用均关闭。192 组竞争中，178 组在其他地址形态上绑定并监听成功，同一准确地址的四种复用组合均不能绑定。180 次固定目的地址的连接全部由原监听描述符接受，客户端收到对应标记，内核监听状态、进程出生及套接字身份保持。探针正常关闭自有套接字，零 Agent、文件工具或外部连接。原样本在开始监听前测绑定，不能据此推断已监听的准确端点被抢走。新结果覆盖该固定地址的流量归属，其他网络规则及后续官方程序另验。首次使用本机不支持的重复状态查询停止，改为读取已核合的内核监听状态后完成。[活动监听回执](fixed-ipv4-active-listener-canary.json)
