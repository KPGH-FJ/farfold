# 准备页面顺序与推进

本片按用户要求把共用准备页固定为「程序 → 账号与服务 → 模型」。尚未安装验证；未启动正式应用或 Agent、未修改正式数据、未执行登录或发送请求。

## 原因与最小修正

- [导航](../../../src/components/AgentSetupNavigation.tsx) 原数组为账号、模型、程序，与实际步骤编号 `0/1/2` 相反；现视觉与方向键、Home/End 导航均按 `0/1/2`，保留未连接及已有账号操作的访问规则。
- [准备页](../../../src/components/AgentSetup.tsx) 原连接完成直接跳到模型，新 connected 入口也无条件以模型为初始页。现新准备连接后进入账号与服务；没有既有来源或模型选项的 connected 入口也先查看账号。已有保存步骤和实际选择继续恢复，不重置原模型、思考或来源。
- 使用流程主按钮逐页继续，仅模型页调用原 `onStart` 保存选择与返回。未知或免登录路线可明确继续；已知认证要求、活跃账号操作和不完整 API 服务阻止账号页的继续动作。程序页仍可进入账号页修正尚未选定的服务。管理、已有对话只读返回以及模型页原有显式重读/认证保护保持。
- [集中提示](../../../src/runtime/setup_presentation_strings.ts) 更新连接后提示并增加两个继续按钮名。本任务未修改 `accountHeading/accountHint/accountFocusedHint`；这些字段由根任务另行处理。

没有新增状态存储、进度版本、账号判定或 Agent 专属分支。原 `step` 含义不变，因此旧记录无需迁移。
