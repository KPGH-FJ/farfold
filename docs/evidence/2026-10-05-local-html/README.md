# 本地 HTML 成果可在 Farfold 内运行

用户提供的 `cat_fishing.html` 是资源内嵌的单文件游戏。旧版静态差异预览禁用脚本，文件系统打开白名单也不包含 HTML，公开网页入口又只接受 HTTPS；三条路径均不能运行该成果。

## 现在怎样使用

打开原对话，点击“浏览器”→“打开 HTML…”并选择文件。已有核实文件也可点击“在 Farfold 中打开”。内容栏内显示文件名、重新载入和关闭；不要求 Agent 重新生成或再发消息。刷新会先重新核实原位置，取磁盘最新版本；用户原文件保持。

本片支持 UTF-8、至多 1 MiB、资源内嵌的单文件 HTML/CSS/JavaScript。独立 WK 页面没有应用接口或文件夹权限；本地页面不能走现有公开网页 MCP 分享。临时 localStorage 在当前页面内可用，收起保留页面，关闭或切换任务不保留页面存档。常规外部资源由 CSP 限制，不将其宣称为操作系统网络沙箱或完整多文件项目服务器。
