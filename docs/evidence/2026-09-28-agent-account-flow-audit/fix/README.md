# Agent 与账号原型修复验证

日期：2026-09-28。范围：唯一原型 `.design/2026-09-26-agent-access-redesign/workbench/`。

## 结果

本轮已修复前一轮确认的三处恢复流程问题。正式应用源码、真实 Agent、账号和凭据未在本轮修改；以下登录与工作结束均为原型模拟。

1. **登录限制可以处理。** 账号页列出真正未结束的具体工作和状态；逐项进入对话处理，再返回原账号步骤。结果未知仍需明确回执，未放松运行、审批及未知结果保护。纯草稿、待恢复和已结束工作不单独阻止登录。
2. **补登录直接进入账号步骤。** 首次失败后的“完成登录”，以及再次发送时预先发现的登录要求，均携带原 Agent、来源、模型、思考和工作位置。API 来源收到 Agent 登录要求时仍保留该 API 服务。
3. **具体问题直达对应设置。** 对话中的账号、模型和连接检查进入对应 Agent 的相关页签，显示来源问题；关闭或返回后回同一对话。固定对话的来源、模型和思考保持只读。

同时补齐：注册准备可以查看，实际继续登录仍受保护；设置里的“Agent 与账号”默认显示已添加条目；多层工作/设置往返保留各自返回位置；同名 Agent 使用 ID 定位和回写，旧无 ID 选择保留名称回退。
