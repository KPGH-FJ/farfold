# 重置与未完成接入返回

范围：当前原型的模拟状态与浏览器交互；未操作真实账号、Agent 程序或安装版。

## 根因

- 重置与无保存数据时的默认启动仍载入日常样例，包含三个已连接 Agent；上一轮仅验证了“首次打开”场景。
- 接入是否完成与程序是否连接混淆：退出未完成的登录后，目录可直接开始，设置入口则切换成管理页。
- 准备进度受入口页面影响；连接中提前退出还会漏存初始向导进度。
