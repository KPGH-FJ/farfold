# 首次打开的 Agent 入口修正

范围：当前 HTML 原型的模拟流程；未改动安装版、真实 Agent 或账号配置。

## 问题与修正

首次打开已清除添加和连接状态，但目录与发送入口只检查“已安装”，导致 Codex、OpenCode、Pi 直接显示“开始新对话”。旧状态测试还把已安装但断开当作可发送，未覆盖首次场景与入口的组合。

统一目录、草稿、准备向导的程序条件：已添加登记、已安装、连接成功、依赖齐全、未移除。连接中、失败、未知和会改变连接的操作继续阻止开始。已连接但账号未知、未做短测仍可尝试；不增加强制登录或短测。
