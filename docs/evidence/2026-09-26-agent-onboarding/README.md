# Agent 准备链补齐

本轮目标：沿用 Farfold 通用客户端和同一准备页，补齐程序依赖、官方账号入口、登录或交互设置、真实短请求检查。对应活动计划 00.13；前序失败保留在 [新增 Agent 实测](../2026-09-26-agent-market-validation/README.md)。

## 行为与边界

- 安装、依赖检查、协议连接、登录流程结束、真实回复分别记录。测试使用普通对话执行路径，并形成可查看的“连接测试”；只有当前选择的消息获准发送、收到本次随机校验文字且正常结束，才通过。
- Amp 必需程序按接入层核对的官方安装声明展示。明确点击安装后，先安全断开空闲连接，再从官方同源分发下载并检查程序，沿用原子选用和安装收据；不运行会改变 shell 设置的安装脚本。运行中的工作不会被强制断开。
- 依赖取消使用本次请求标识；迟到取消不能影响后续操作。断开尚未完成时取消，不再开始下载。程序检查在配置锁内对实际选中的启动配置执行；未知 Agent 不推测依赖，也不因此被禁止连接。
- 标准终端认证保留原启动参数并追加声明参数，允许空附加参数。Qwen 已核验的终端扩展转为官方交互设置入口；完成后明确返回检查，不将进程退出当作账号可用。终端关闭等待真实回收，失败保留状态。
- 账号创建和权益使用官方页面；密码、密钥、验证码、条款仍由用户处理。没有读取或复制已有 Agent 认证文件。
- 测试的发送、审批、停止、模型选择均复用普通对话。独立草稿范围避免误用用户草稿；程序、账号、使用方式、服务或模型变化会使旧验证失效；取消及迟到结果不能恢复旧成功。

Qwen 的共享 API 配置没有开放：已安装版本的模型提供方设置可能优先于命令行或环境提供的地址、密钥与模型，未找到可保证完整覆盖且无需写外部配置的官方入口。本轮提供官方交互设置与真实测试，不以此替代共享服务能力。

## 官方依据

- [ACP 认证协议](https://agentclientprotocol.com/protocol/v1/authentication)：标准认证与终端方法。
- [ACP Registry](https://agentclientprotocol.com/get-started/registry)：安装声明及其范围。
- [Amp CLI 官方说明](https://ampcode.com/docs/cli)：所需程序；下载来源 `static.ampcode.com`。
- [Qwen Code 认证说明](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/auth/)：官方账号与服务设置方式。另对本机目录安装的 0.24.5 发布包进行只读入口和优先级核对，没有改包。
