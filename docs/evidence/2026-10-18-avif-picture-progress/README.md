# AVIF 画面推进分项证据

2026-10-18，使用同一份完整的 2267 字节官方 AVIF。ImageIO 读取的五个索引仅用作独立像素参考；索引 3、4 保留为同一渐变类，不能据此认定完整五帧时序。

受控 WebKit 26.5 在普通 `img` 和真实共用 `MessageContent` 两个场景分别保存 37、40 张截图，各 13/13 检查通过。77 张 PNG 经独立解压、像素比对和固定阈值重算，均支持四类可区分画面的局部推进。

生产组件显式展开后，采样前后保持同一节点和原始来源；可用预览槽位从 4 变为 3，收起后移除来源并恢复为 4，随后约 372ms 及被动重绘未重建来源。浏览器、服务、两个进程组和三路数据流均有关闭记录。

另两例 Python 故障控制验证了清理路径；它们不是浏览器或播放测试。`supervisor.main()` 的预期失败返回值与外层 driver 自然退出码分别记录。

本分项未验证正式 Farfold/WKWebView 或真实 Agent 返回媒体，也不证明完整五帧、顺序、帧时长、循环、方向、内存上限或 P13 整项完成。实际记录与 SHA 见 [verification.json](verification.json)。
