## 数据与状态边界

- [program_progress.ts](../../../src/runtime/program_progress.ts) 仅在 `download` 阶段格式化收到的字节数。收到量必须为非负安全整数；总量必须为正安全整数且不小于收到量，否则只显示已下载量。`0` 与尚无测量值分别处理，没有推算百分比、速度、剩余时间或不存在的总量。
- 已核对未改动的 [install_job.rs](../../../src-tauri/src/install_job.rs)：下载量来自实际接收并累计的响应块长度，总量来自响应提供的 `content_length`。下载开始尚无测量值，后续解压、校验、检查和完成使用各自阶段。本片没有增加后端测量或更改其含义。
- 普通程序卡片和 [ProgramManager](../../../src/components/ProgramManager.tsx) 按当前 Agent ID 读取现有进度。连接、空闲状态不显示下载尺寸；阶段更新到解压、校验或检查时，旧尺寸也不再显示。原取消入口及目标 ID 没有改变，没有因展示字节而新增安装、选择或卸载操作。
- [AgentPrerequisites](../../../src/components/AgentPrerequisites.tsx) 仍使用原操作对象与 `generation` 守卫；[preparation.ts](../../../src/runtime/preparation.ts) 仍按请求 ID 取消同一依赖任务，已完成任务忽略迟到消息。Agent 切换、组件清理后的旧回调不能进入新目标的进度显示。取消等待实际结果的行为保持，未把取消点击当作已结束。
- 候选程序在检查、完成时继续使用原候选文案与通知；显示字节不会把“已准备候选”改成“已选用”，也不触发当前程序断开或自动选择。
