# 配置操作返回与明确读取：前端修复证据

本记录只覆盖当前进程内的前端控制器、真实组件回调及状态测试。起点为安装候选 `c22ed6c`；该候选的实际配置取消、非零退出和重查结果由主记录保留。本次前端工作未启动 Agent、未运行配置程序、未修改用户配置或正式应用，不代替新候选安装验收。

## 已修复范围

- 目录卡和准备页按冻结操作用途显示配置或登录进度。进度入口只定位同一账号页，保留选择、入口意图及已有操作，不重复启动。已结束操作在断线后仍能从程序页返回结果页。
- 相同退出状态只显示一次；重查后连接结果与原退出结果的不同含义仍分别保留。共享忙任务、更新提示、终端错误不再把服务配置统称为登录。
- Hub、EmptyState 自动新稿、旧发送/模型回调，以及恢复失败后的新稿出口，共用 `AgentPreparation` 的原有目标标记。标记阻止隐式读取和首次发送；既有对话、其他目录和 API 来源保留原边界。原模型、思考选项及未发送内容不改写。
- 历史恢复失败或已有新稿返回准备时，沿原目录和选择进行独立模型读取，完成或暂离仍返回原页面；不改旧对话、不自动创建对话或发送消息。
- 该返回上下文明确保留原页面，即使 Agent 尚未有准备完成标记，也不被切成首次使用后跳转新对话。
- 原稿独立准备复用既有页面局部进度，但使用自己的目录范围，不借用另一目录的未完成向导；旧进度与其待办指针保留。读取失败带回的额外默认值不写回原选择；目录别名与确认目录上的认证要求都参与返回保护。
- 显式读取开始时保留标记，只有当前请求返回、选择实际恢复且读取无已知错误时清除。迟到、失败、选项不一致及带失败状态的返回对象不能清除。`readError` 仅记录该次读取的安全失败原因；后续短测失败不冒充读取失败。
- 通用配置动作自身使用已有位置查询确认实际目录，审阅与运行使用同一位置；等待确认时提供状态并禁用运行。Setup 的读取目标使用同一确认目录，用户显示/保存的路径保持原值。该处理也覆盖独立账号入口，未增加路径映射记录。
