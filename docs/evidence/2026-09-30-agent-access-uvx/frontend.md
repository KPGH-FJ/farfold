# 安装工具准备界面

日期：2026-09-30。本材料记录前端源码与受控 IPC 响应验证，不代表真实 uv/Python 下载、Agent 连接或模型请求成功。

## 接口与行为

复用现有 `agent_preparation`、`agent_dependency_install` 和按请求身份取消的接口。后端为未注册目录条目返回通用依赖列表，界面不按 Agent 名称或分发类型写分支。

依赖新增 `requiredForInstall` 和 `requiredForUse` 两个用途字段。前端对旧数据保留“用于使用、不额外阻塞安装”的默认语义。uv/Python 安装工具只参与安装前置判断；既有运行依赖继续参与使用条件。准备安装工具不会调用断开回调，安装运行依赖仍先执行已有工作保护。安装中的忙状态独立于已知准备事实；失败不撤销未受影响的使用条件。

首次安装页面在安装前置条件完成前保留提示并禁用主程序安装，实际处理器也拒绝不满足条件的调用。已安装程序的连接不要求安装工具重新存在。原有返回、模型选择、请求验证语义继续独立判断。

进度中的检查/完成文案说明所需程序的检查和准备，不把依赖检查描述成 Agent 连接成功。取消发出后继续等待本次安装结果；失败可重试；刷新程序列表不丢失进行中的安装，切换条目不会接收旧条目的迟到结果。
