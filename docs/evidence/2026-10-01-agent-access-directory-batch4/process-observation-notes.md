# 进程身份汇总修正

本批第一次 `collect_observed.py` 因旧断言退出 1，没有生成最终清单。原采样中 PID 66992 的启动时间始终为 `Thu Oct 1 03:20:54 2026`，但程序标题从 `node` 变成 `npm install @minimax-ai/code@0.2.7`，见 `cwd-minimax-install.json` 与 `minimax-installing.json`。这是同次启动中观察到的标题变化，旧脚本将其误当作 PID 复用。

本批辅助脚本改用 PID 加启动时间形成身份，并保留所有实际观察到的程序标题；不同启动时间的同 PID 分开保存。退出核对沿相同身份检查，不因标题改变或父进程变化就误称已退出。修正只涉及本批取证脚本，没有改应用、停止其他用户进程或重写原始采样；历史收据保持原样。
