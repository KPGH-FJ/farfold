# 内嵌公开网页与文件交付里程碑

本轮在`cee3f86`及保留的未提交工作区上增量接入。用户于2026-10-04批准继续开发、认可打开/读取/关闭/切页收回，并要求关键节点提交推送。文件交付沿先前已批准方案保留。未安装或替换正式应用，未启动真实Agent、模型或账号登录。

## 用户可见行为

- 内容栏增加“文件与输出 / 网页”；无产物的已有对话也能打开公开HTTPS页面、读取带网址/时间的文字快照、关闭网页。
- 切换任务、关闭内容栏、改变主要布局和显示覆盖浮层前，等待真实网页关闭确认。失败保留原页面归属与可见重试；快速连续切换只执行最新目的地。
- 历史恢复回执不抢走等待中的新导航；设置返回与仅改变布局时仍保留原身份恢复逻辑。
- 文件交付保持核实磁盘原文件后打开/定位/不覆盖另存，或由用户明确选文件与导出文本快照。意见仍加入原输入框，由用户发送；完整真实Agent返工尚未验证。

## 实现与边界

独立非持久WK视图位于现有主窗口，没有应用脚本或IPC桥；无需新依赖及实验性Tauri接口。main自定义命令核验真实调用来源，能力与应用事件只面向main。五命令公开接口和退出清理见[实际命令验证](command-validation/README.md)。不保存浏览器登录态、不访问日常浏览器资料，不开放秘密接管或登录。

网址准入、已知登录标记拒绝不构成网络沙箱或完整登录检测。工作文件夹也不是Agent的操作系统沙箱。生产new/load仍未注入浏览器MCP；Agent自己的工具/MCP保持原能力。旧受控MCP结果见[前片证据](../2026-10-03-workbench-delivery/README.md)，不作为当前正式分享已完成的证明。
