# Agent 接入与密钥管理：实施与验收

2026-09-22。用户批准 P0–P5 计划；本记录区分源码、测试、安装版自动化和真人验收。

## 已实现的责任边界

- 独立密钥设置页；已添加列表、统一添加入口、二级程序与认证管理。保留 LifeModel 和项目工作开关。
- 登录要求仅从明确协议认证错误产生，按 Agent/项目保存于内存；无登录方式和有登录方式均不自动阻断。设置期间保留原对话组件和输入草稿，返回不自动发送。
- 有限目录发现多份程序，同文件别名去重；版本探测有单次/整体预算。受管理新安装登记目录；旧安装保留。移除前保留已知实例清单，撤销共享授权，不删会话索引。
- 卸载只接受已登记实例标识，后端检查目录归属、根目录替换、当前选择、其他接入使用及连接状态。外部/缺少归属记录的历史安装禁止直接卸载。安装管理列出实际入口或安装目录，不把 Node 路径当作接入组件位置。
- 新密钥只入 Keychain，替换和说明编辑分开；固定 Agent 授权不重复选择对象。部分保存成功如实提示，可继续授权；新服务配置能力不足时提供官方指引。
- 连接启动时原子读取凭据与版本快照；修改后标记待重连；撤销/删除不伪称已清除旧进程副本。真实请求按连接与会话模型显示，不能确认凭据来源时不称 Key 验证成功。无新事件账本。
