## 实现

该程序可经现有授权把命令交由 Farfold 执行。点停止后，Farfold 只对当前请求实际启动并确认全部退出的自有命令发布退出回执。回执关联原连接、请求和命令，可在 Agent 的原轮结束前后呈现。Agent 自有工具仍以它报告的事件为准。连接结束或会话关闭后退出监听，原命令清理由同一原进程管理机制继续负责。 [产品契约](../../../PRODUCT.md)
