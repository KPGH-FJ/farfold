## 实际使用验收

[当前首发名单](agent-first-release.md)逐家从正式 Farfold 的正常入口验证产品契约八项。用户选定真实程序、账号服务和模型，核首次有效请求、工作中控制、结果和冷开后继续。工具、技能、审批和文件方式按各自已承诺的范围验到实际结果。

- **找回旧工作。** 用户能从常用入口自行定位旧对话，打开真实正文，重开后问一个只有原前文才能回答的问题。分别记录查找、正文和沿原对话续答，也核目录、服务及原配置。已知 ID 作为补充入口。
- **获得可用成果。** 真实任务做到用户可以使用的结果。文件返工使用已授权的工作副本，确认正确新版、原件保持、实际打开或另存交付。
- **控制和恢复。** 两条任务在途，从目标对话点「停止」，核同一请求及其正在执行的工作实际停止，另一条继续。中断后核原身份配置、正文、草稿、附件及待发保持，未知时沿原保护处理，保持无自动重发。
- **并行留证。** 条件独立的多家用同一候选并行验，使用可区分的样本和结果。每家记录候选与 Agent 版本、服务与模型、原对话与请求、实际结果和证据。同家双对话与跨家结果分别核，共享账号、全局设置或样本影响归因时错峰。结果分别标实测通过、实测失败、未测试、结果未知或所缺条件。

每次更新条目必须记录最新结论、对应提交与直接证据、实际覆盖的Agent/模型/服务/系统版本及剩余缺口，并与状态页同批同步。共用修复更新所有关联任务；已修问题从当前待修项移出，原失败与当时未测范围保留在历史证据中。源码、受控测试、正式应用及真实Agent效果按实际覆盖范围表述；下一步执行安排归唯一活动计划。
