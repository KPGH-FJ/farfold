## 本版方向

- 灰白工作台、清晰文字层级、深灰主动作、只用于含义明确状态的颜色。
- 新对话是默认入口，最近对话、待回应和我的 Agent 从侧栏到达。
- 接入与管理采用同一套程序／账号与服务／模型分区，已有接入直接管理，不反复经过首次使用流程。
- 把具体账号、服务来源、模型和工作位置配对展示；未知信息写明未提供。
- 决定前展示变化与影响，操作后根据明确结果提供下一步。未确认不冒充成功。

## 草稿与对话

可以先写草稿；首次发送前必须显式选工作文件夹，取消保留输入。移除工作文件夹回到未选择状态。文件夹是工作位置，不等于访问权限边界；分组只整理对话。草稿换 Agent 会比较前后选择，保留正文与附件，不自动发送。

首次接纳后固定 Agent 与服务来源。模型和思考深度可在工作已结束、当前能力支持时显式确认后更改；忙碌、审批、停止未确认及设置结果未知时保护变更。配置前后表说明旧值、新值与不变的来源；失败保留旧值，未确认暂停发送。

审批、提问、待发、停止和恢复都有独立状态。停止确认前不显示已停止；恢复后重新确认权限，保留待发但不自动执行。编辑重发明确追加新消息，已有草稿会先保护。查找逐处定位匹配。

顶部导览会补充缺少的示例对话、分组和服务。只对完全未改变的初始 Agent 夹具补充演示准备状态；明确移除、配置与未完成操作保持不变。不会替换已有演示草稿。首次打开与显式重置仍从空白起步。

## 本轮补齐的五类交互

- **对话与消息菜单**：对话页可移到分组、确认删除、查看工作位置的成功／失败演示、用相同设置再开。消息可编辑后追加、准备再发或从这一条新开；新开只带入选中的文字与附件，不伪称继承原历史上下文，原草稿先保护，来源不完整时必须重新选择。
- **长命令**：新草稿和对话中的命令列表提供 6 个布局样例，支持搜索名称或描述、长内容换行与滚动；选择仅填入命令并保留草稿，不执行。
- **附件收纳**：新草稿、对话输入及已发消息共用附件列表，默认预览前三项，可展开全部与完整位置；展开按钮提供 `aria-expanded`、`aria-controls` 和键盘操作语义。实际读屏体验仍需验证。
- **附加配置**：首发前从“更多设置”、首发后从输入区对话设置进入。逐项显示名称、当前值、说明、作用对象与生效时点，未提供的内容明确未知；仅声明的可变选项可选，未知类型只读。开启“原型选项样例”可体验比较、待保存、成功、失败、未知和核对；失败保留旧值，未知暂停发送，重启后待保存也保留为未知。
- **提醒**：通用设置新增可操作的提醒与声音偏好、权限允许／拒绝／不可用演示、返回重查及本页测试卡片。卡片按对话身份定位目标，不批准、不发送；关闭提醒或撤回模拟权限会清除预览。没有请求系统权限、播放声音或发送桌面通知。

`Collaboration mode=Default`、`Fast mode=Off` 只复现既有审查里的名称和单个当前值，不推测其他可选值、性能或费用。用于验证保存流程的可交互选项独立标为样例，不代表任何真实 Agent 能力。

## 文件与网页

文件、差异、预览和输出在独立内容栏；失败可以重试本文件或选择其他内容，不锁住整个对话。意见标明正在查看的版本，回到原输入区后由用户发送。真实核盘、另存和修改交付仍待正式实现验证。

首发前可在选择 Agent 和工作位置后打开示例网页。打开不分享；许可只针对当前页。收起保留许可，换页、关闭、Agent／来源／工作位置变化撤回。草稿导航时页面状态保留在浏览器内存中，不把可见网页当作已发送附件。这里没有访问真实网络；正式许可须由真实工具请求触发。

对话网页演示同样区分查看和许可，连接结束撤回。静态网页内容、代码与文件都明确为样例，不冒充本地磁盘或联网结果。

## Agent 与服务

目录使用当前 29 个精确身份与已有官方图标。10 个既有条目提供能力夹具，其余 19 个不推测认证、模型和历史能力。目录数量不等于接入通过。

程序维护按当前使用、检查进度、更新影响和可折叠位置版本组织。移除先说明接入、受管理程序、账号和历史各自范围；旧受管理版本可独立清理。当前工作保护破坏性变更。

登录是缺少条件时的步骤，只有模拟回执能改变模拟状态。官方登录、终端、注册和密钥交互都是体验样例，不调用真实账号或密钥。保存 API 服务与选给 Agent 使用分开，来源地址／格式变更呈现前后差别，不自动发旧 Key。未保存退出保留继续编辑、保存或放弃选择。

## 对话库、导入与设置

对话库显示未发内容与队列数量，提供活动、待回应、进行中、归档等筛选。搜索限标题、Agent、分组和工作位置等元数据。移动前展示对象与当前分组；删除列出范围并保护有未完成工作的对话。

带入已有对话区分列表、正文与继续能力，支持 Agent 搜索、加载更多、失败重查和只读。未取得正文或无法继续时如实说明，不伪造空白成功历史。

设置按外观、整理、维护和隐私组织。数据范围与卸载说明分开，诊断按类别先预览。清除、更新与诊断导出只演示范围和结果，不实际执行。提醒已提供上述完整模拟交互；LifeModel 继续保留未启用说明。

## 演示工具与证据边界

- **改版导览**：正常页面入口与评审范围；状态切换留在“原型场景”等独立评审工具，不混入日常主操作。
- **载入示例**：明确确认后替换当前演示，评审意见保留；与非覆盖的导览补充不同。
- **重启演示**：恢复本浏览器保存的内容，未结束结果待确认，不自动发送。网页只保留当前页面生命周期的内存状态。
- **重置演示**：确认后清空模拟工作；不影响正式 Farfold。
- **反馈**：只保存本浏览器，由用户决定是否导出；不会自动发送。

可点击原型只证明覆盖到的设计与模拟状态转换。系统菜单、真实通知与声音、剪贴板、文件选择器、访达、外部登录、应用真实退出和安装版数据清除没有完成实机验收。样例测试通过不能转写为 29 家真实 Agent 或正式应用通过。

旧原型06的清理与首次接入记录属于历史证据：[2026-09-28 清理复核](../../../docs/evidence/2026-09-28-prototype-cleanup-recheck/README.md)、[入口修复](../../../docs/evidence/2026-09-28-agent-entry-fix/README.md)。旧记录中的模型永久固定、无文件夹直接发送、手动断开等描述已被当前产品契约覆盖。
